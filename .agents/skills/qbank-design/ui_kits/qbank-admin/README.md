# Qbank owner admin — UI kit

The same shell as `../qbank-app`, loaded with `window.QB_ROLE = "admin"`. Tabs are Home, Import, Admin and Settings. Her screens show a read-only banner and have no answer or edit controls. `Admin.jsx` adds AdminHome (Semesters and courses, Weeks, Her account, Repair), AdminWeeks (rename a week label, move a set) and AdminAccount (reset email or a temporary password).
