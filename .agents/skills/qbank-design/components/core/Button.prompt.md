Tappable action; primary for the one main action on a screen (Check answer, Import), secondary/quiet for the rest.
```jsx
<Button size="lg" fullWidth>Check answer</Button>
<Button variant="secondary" size="sm" icon="rotate-ccw">Restore</Button>
```
- Press = darker fill + scale(0.98). Disabled = 40% opacity.
- Sentence case labels, verbs first.
